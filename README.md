🚀 РЯДОМ — Telegram Bot
РЯДОМ — это мощный и полностью кастомизируемый Telegram-бот для знакомств с богатым функционалом, системой лайков, взаимных симпатий и административной панелью.
Живой проект — готов к деплою (перенос готового программного обеспечения (бота) с компьютера разработчика на сервер или в облачную инфраструктуру)
Поддержка фото, геолокации, интересов
Умный поиск по интересам
Полноценная админ-панель
SQLite — легковесная база без лишних заморочек

Демонстрация

Бот в работе:
🔥 Регистрация → 📸 Фото → 👤 Имя → 🎂 Возраст → 👫 Пол → 📍 Город → ❤️ Интересы → 📝 О себе

После регистрации доступны: просмотр анкет, лайки, взаимности, поиск по интересам, настройки поиска и статистика.
Архитектура проекта
ridon.py (Основной файл бота)
ваше название.db (SQLite база данных)

Структура БД

users — профили пользователей
likes — лайки и взаимные симпатии
reports — жалобы
profile_views — просмотры анкет
chats — чаты (готово к расширению)
admin_messages — рассылки от администрации

Функционал

Для пользователей

Команда / Кнопка	Описание
/start	Регистрация / вход
👀 Смотреть анкеты	Показ анкет по настройкам
🔍 Поиск по интересам	Ищет людей с твоими интересами
❤️ Лайк	Отправить симпатию
➡️ Дальше	Следующая анкета
⚙️ Настройки поиска	Пол, возраст
📊 Мой профиль	Просмотр/редактирование
❤️ Кто меня лайкнул	Список лайкнувших
🚫 Пожаловаться	Отправить жалобу
🗑️ Удалить анкету	Полное удаление профиля
🆘 Помощь	Справка

Для администраторов

Команда / Кнопка	Описание
/admin	Вход в админ-панель
📊 Статистика	Кол-во пользователей, жалобы
👥 Все пользователи	Список (ID, имя, статус)
⚠️ Жалобы	Просмотр необработанных жалоб
🔍 Найти пользователя	Поиск по ID или имени
🚫 Забанить	Бан / разбан
📨 Отправить сообщение	Рассылка или личное сообщение

Модели и технологии
Язык: Python 3.9+
Библиотека: python-telegram-bot v20+

Быстрый старт
1. Клонируй репозиторий
git clone https://github.com/X1nQ2/Sekretory/blob/exam/ridon.py
cd ryadom-bot

2. Установи зависимости
pip install python-telegram-bot
SQLite встроен, дополнительные пакеты не нужны

Настрой токен и админов
В файле ridon.py
BOT_TOKEN = "" Ваш токен
ADMIN_IDS = [] Твой Telegram ID
DB_PATH = "" название вашей бд

4. Запусти бота
python ridon.py
